# Return Policy

Customers can return most items within 30 days of delivery.

Returned items must be unused, undamaged, and in their original packaging.

Customers should include their order ID when contacting support about a return.

Some items cannot be returned unless they are faulty, including personalised products, hygiene-sensitive products, and final sale items.

If a return request is approved, the customer will receive return instructions from the support team.
