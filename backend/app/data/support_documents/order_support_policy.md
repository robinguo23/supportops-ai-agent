# Order Support Policy

Customers should provide their order ID when asking about an order.

Order support can help with order status, missing orders, delayed orders, wrong items, delivery problems, and order updates.

If an order ID is recognised by the system, the customer can receive the current order status and estimated delivery information.

If an order ID cannot be found, the customer may request human support so the support team can investigate the issue.

Customers should double-check the order ID format before requesting human support.
